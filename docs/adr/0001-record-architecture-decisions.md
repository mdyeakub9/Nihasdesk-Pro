# ADR 0001: Record architecture decisions

Date: 2026-10-23 · Status: Accepted

## Context
The project is built largely with AI assistance across many sessions. Decisions made in chat are lost.

## Decision
Every significant decision is recorded as a numbered ADR in `docs/adr/` (context, decision, consequences). A decision made in chat is not final until it has an ADR or a doc update.

## Consequences
New sessions (human or AI) can recover the reasoning behind the design.

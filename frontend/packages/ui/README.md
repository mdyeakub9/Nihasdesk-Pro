# ui

Design system: tokens, components, Storybook (later).

- `src/styles.css` — design tokens as CSS variables (light/dark), mapped to Tailwind. Placeholder values until Figma tokens arrive.
- `src/components/` — shadcn/ui components (`components.json`); add new ones with the shadcn CLI or by hand in the same style.
- `cn()` — class name helper.
